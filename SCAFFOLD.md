# SCAFFOLD.md — Generic project bootstrap on this stack

A runbook for standing up a **new, domain-free project with the same technical
setup as this one**: a vanilla-JS SPA built with Vite, served by Netlify with
Netlify Functions as the API, a Neon Postgres database through Drizzle ORM,
Clerk authentication, a PWA layer, and Vitest + jsdom tests.

Everything below is infrastructure. The only "feature" shown is a throwaway
`items` key/value example, used purely to demonstrate the DB/handler pattern.
Delete it and add your own domain modules in its place.

> Companion doc: `DESIGN.md` describes the visual language. Reproduce a minimal
> version of it for any new project so UI stays consistent.

---

## 0. Scope

**Covers**

- Repository layout and file responsibilities
- Build tooling (Vite), test tooling (Vitest + jsdom), lint/format/typecheck
- Netlify hosting, `netlify.toml`, Netlify Functions conventions
- Postgres via Neon + Drizzle ORM + migrations
- Clerk authentication (client + server JWT verification)
- PWA (manifest, service worker, install prompt)
- Security/caching headers
- CI and environment variables

**Does not cover**

- Any business logic, data model or third-party API specific to a domain
- Visual design decisions beyond the token/bootstrap layer (see `DESIGN.md`)

## 2. Prerequisites

1. **Node 24** installed (`nvm use` reads `.nvmrc`).
2. Accounts / projects:
   - **Netlify** site (for hosting + Functions + the Neon extension).
   - **Neon** Postgres database (the Netlify Neon extension injects
     `NETLIFY_DATABASE_URL` in production).
   - **Clerk** application (publishable key + issuer URL).
3. Netlify CLI available: `npx netlify` (or install `netlify-cli` globally).
4. A `.env` file (gitignored) with the values in [Step 4](#step-4--environment).

Install the dependencies from [Step 2](#step-2--packagejson).

### Step 4 — Environment

Create `.env` (gitignored) and commit `.env.example` documenting each key.
Netlify Dev loads `.env` automatically; the production values are set in the
Netlify UI (or injected by the Neon extension).

```
# .env.example

# Client: Clerk publishable key (safe to expose to the browser).
VITE_CLERK_PUBLISHABLE_KEY=pk_test_xxx

# Server: Clerk issuer URL used to fetch the JWKS for JWT verification.
VITE_CLERK_ISSUER_URL=https://your-app.clerk.accounts.dev

# Postgres connection string (provided by the Neon extension in production).
NETLIFY_DATABASE_URL=postgres://user:pass@host/db?sslmode=require
```

> Both Clerk values start with `VITE_` because the frontend needs the
> publishable key and `constants.js` reads it from `import.meta.env`; the issuer
> URL is only used server-side. Never put a Clerk **secret** key in `VITE_*`.

**`src/app/shell.js`** — shared boot used by every page entry:

```js
import { initClerk, getClerk } from '../auth/clerk.js';
import { registerServiceWorker } from '../pwa.js';

/**
 * Boot the page-agnostic shell: initialise Clerk, react to sign-in/out, and
 * register the service worker. Page entries then mount their own content.
 */
export async function bootShell() {
  const clerk = await initClerk();

  // Reload when the signed-in user changes so server-backed state is re-read.
  let lastUserId = clerk.user?.id ?? null;
  clerk.addListener(() => {
    const nextId = clerk.user?.id ?? null;
    if (nextId !== lastUserId) window.location.reload();
  });

  registerServiceWorker();
  return { clerk };
}
```

```js
export function registerServiceWorker({ enabled = import.meta.env.PROD } = {}) {
  if (!enabled || !('serviceWorker' in navigator)) return false;

    navigator.serviceWorker.register('/sw.js').catch((err) => {
      console.error('Service worker registration failed:', err);
```

### Step 7 — Server helpers

**`netlify/utils/auth.ts`** — Clerk JWT verification via JWKS:

```ts
import { createRemoteJWKSet, jwtVerify } from 'jose';

const JWKS = createRemoteJWKSet(new URL(process.env.VITE_CLERK_ISSUER_URL!));

async function verifyToken(token: string) {
  try {
    const { payload } = await jwtVerify(token, JWKS);
    return payload;
  } catch (error) {
    console.error('Token verification failed:', error);
    return null;
  }
}

/** Resolve the authenticated user id from an `Authorization: Bearer` header. */
export async function getUserId(event: {
  headers?: Record<string, string | undefined>;
}): Promise<string | null> {
  const token = event.headers?.authorization?.split(' ')[1];
  if (!token) return null;
  const user = await verifyToken(token);
  return typeof user?.sub === 'string' ? user.sub : null;
}

export function unauthorized() {
  return { statusCode: 401, body: JSON.stringify({ message: 'Unauthorized' }) };
}
```

**`netlify/utils/request.ts`** — safe JSON parsing + shared limits:

```ts
type JsonEvent = { body?: string | null };
type HandlerResponse = { statusCode: number; body: string };

export const MAX_BATCH_SIZE = 500;

export function badRequest(message = 'Bad Request'): HandlerResponse {
  return { statusCode: 400, body: JSON.stringify({ message }) };
}

export type JsonBody =
  { ok: true; value: Record<string, unknown> } | { ok: false; response: HandlerResponse };

export function parseJsonBody(event: JsonEvent): JsonBody {
  if (!event.body) return { ok: true, value: {} };
  let parsed: unknown;
  try {
    parsed = JSON.parse(event.body);
  } catch {
    return { ok: false, response: badRequest('Malformed JSON body.') };
  }
  if (parsed === null || typeof parsed !== 'object' || Array.isArray(parsed)) {
    return { ok: false, response: badRequest('Expected a JSON object.') };
  }
  return { ok: true, value: parsed as Record<string, unknown> };
}
```

**Handler contract:** every file in `netlify/functions/` exports
`handler = async (event) => ({ statusCode, body: JSON.stringify(...) })`.
Reads that expose another user's data should accept an explicit read-only
`shareToken` capability; writes must resolve the caller with `getUserId(event)`
and **never** trust a `userId` from the request body.

**Example endpoint — `netlify/functions/items.ts`** (delete once you add real
features):

```ts
import type { HandlerEvent } from '@netlify/functions';
import { eq, and } from 'drizzle-orm';
import { db } from '../../db';
import { userItems } from '../../db/schema';
import { getUserId, unauthorized } from '../utils/auth';
import { badRequest, parseJsonBody } from '../utils/request';

export async function handler(event: HandlerEvent) {
  const userId = await getUserId(event);
  if (!userId) return unauthorized();

  if (event.httpMethod === 'GET') {
    const rows = await db
      .select({ itemId: userItems.itemId })
      .from(userItems)
      .where(eq(userItems.userId, userId));
    return { statusCode: 200, body: JSON.stringify(rows) };
  }

  if (event.httpMethod !== 'POST' && event.httpMethod !== 'PUT') {
    return { statusCode: 405, body: JSON.stringify({ message: 'Method Not Allowed' }) };
  }

  const parsed = parseJsonBody(event);
  if (!parsed.ok) return parsed.response;

  const { itemId, present } = parsed.value;
  if (typeof itemId !== 'string' || itemId.length === 0) {
    return badRequest("'itemId' must be a non-empty string.");
  }
  if (typeof present !== 'boolean') return badRequest("'present' must be a boolean.");

  if (present) {
    await db.insert(userItems).values({ userId, itemId }).onConflictDoNothing();
  } else {
    await db
      .delete(userItems)
      .where(and(eq(userItems.userId, userId), eq(userItems.itemId, itemId)));
  }

  return { statusCode: 200, body: JSON.stringify({ itemId, present }) };
}
```

```js
    caches
      .open(CACHE)
      .then((cache) => Promise.all(SHELL.map((url) => cache.add(url).catch(() => {}))))
      .then(() => self.skipWaiting())
  );
});

self.addEventListener('activate', (event) => {
  event.waitUntil(
    caches
      .keys()
      .then((keys) => Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k))))
      .then(() => self.clients.claim())
  );
});

self.addEventListener('fetch', (event) => {
  const { request } = event;
  if (request.method !== 'GET') return;
  const url = new URL(request.url);
  if (url.origin !== self.location.origin) return;
  if (url.pathname.startsWith('/.netlify/')) return; // never cache functions

  if (request.mode === 'navigate') {
    // Network-first so a new deploy is picked up, cached shell as fallback.
    event.respondWith(
      fetch(request)
        .then((response) => {
          const copy = response.clone();
          caches.open(CACHE).then((cache) => cache.put('/', copy));
          return response;
        })
        .catch(() => caches.match('/index.html'))
    );
    return;
  }

  if (url.pathname.startsWith('/assets/') || url.pathname.startsWith('/icons/')) {
    event.respondWith(
      caches.match(request).then(
        (cached) =>
          cached ||
          fetch(request).then((response) => {
            if (response.ok) {
              const copy = response.clone();
              caches.open(CACHE).then((cache) => cache.put(request, copy));
            }
            return response;
          })
      )
    );
  }
});
```

## 5. Architecture rules (keep these when adding features)

1. **Frontend stays framework-free.** Compose DOM with small factory functions
   (`createXModal()` → `{ show, close }`), keep state in plain exported objects,
   and keep rendering in `src/ui/`.
2. **TypeScript only on the backend** (`netlify/**`, `db/**`, `drizzle.config.ts`).
   Frontend is `.js` with JSDoc where useful.
3. **One HTTP concern per function file.** Share validation/db logic in
   `netlify/utils/` and import it from thin handlers.
4. **Never trust client identity.** Resolve the user with `getUserId(event)`;
   a `shareToken` is a read-only capability, never a write path.
5. **All client requests to authenticated endpoints go through
   `authenticatedFetch`**; never hand-roll the Authorization header.
6. **Migrations are generated, never hand-written.** Change `db/schema.ts`,
   then `npm run db:generate` + `npm run db:migrate`.
7. **Escape untrusted strings** before interpolating into `innerHTML`
   (use a shared `escapeHtml` helper).
8. **Eager-load the shell, lazy-load the dialogs.** Use dynamic `import()` for
   modals/heavy views so they ship as separate chunks.
9. **Respect the design tokens** in `src/styles.css` and keep `DESIGN.md`
   current.
10. **Add tests** for behaviour changes; keep the four CI gates green
    (lint, format, typecheck, test).

## 7. Pitfalls

- **Functions 404 on port 5173.** The bare Vite server doesn't serve them; use
  `npm run dev:netlify` (8080).
- **`npm ci` fails on Linux after a Windows lockfile.** Declare optional
  websocket peer deps (`bufferutil`, `utf-8-validate`) explicitly.
- **Drizzle "table already exists".** Baseline migrations if the DB predates
  Drizzle.
- **`drizzle-kit` version drift.** Stay on the 0.31+ CLI API.
- **Service worker serving stale code.** It's production-only and network-first
  for navigations; bump the cache name when the shell strategy changes.
- **CSP blocking Clerk.** Keep it report-only and watch the console before
  enforcing.
